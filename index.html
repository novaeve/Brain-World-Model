03 · 优化：v0 → v1

架构没变，变的是五个 loss 怎么配。

总损失是五个任务损失的加权和，两个版本只有权重 \(s_t\) 的算法不同。

$$\mathcal{L}=\sum_{t\in\mathcal{T}} s_t\,\mathcal{L}_t,\qquad \mathcal{T}=\{\text{gene},\ \text{int},\ \text{ct},\ \text{reg},\ \text{sp}\}$$
v0 · 初始损失归一化 $$s_t=\frac{1}{\bar{\mathcal{L}}_t},\qquad \bar{\mathcal{L}}_t=\frac{1}{200}\sum_{k=0}^{199}\mathcal{L}_t^{(k)}$$

权重在第 200 步后固定。损失数值大的任务不一定梯度大，各任务实际拿到的梯度并不相同。

v1 · 梯度范数均衡 $$g_t=\big\lVert\nabla_{\theta_{\text{enc}}}\mathcal{L}_t\big\rVert_2,\qquad \hat g_t\leftarrow 0.9\,\hat g_t+0.1\,g_t$$ $$s_t=\frac{\bar g}{\hat g_t},\qquad \bar g=\frac{1}{|\mathcal{T}|}\sum_{u\in\mathcal{T}}\frac{\hat g_u}{\bar{\mathcal{L}}_u}$$

每 50 步对编码器参数测一次各任务的梯度范数，使 \(s_t\hat g_t=\bar g\)：每个任务对编码器的梯度一样大。\(\bar g\) 取 v0 权重下的平均梯度，总梯度的量级不变。即 GradNorm（Chen et al., 2018）取 \(\alpha=0\) 的目标，权重按比例直接求出。

五个任务损失 $$\mathcal{L}_{\text{gene}}=\frac{1}{|M|}\sum_{(c,g)\in M}\big(\hat v_{cg}-v_{cg}\big)^2$$ $$\mathcal{L}_{\text{int}}=-\log p_{\text{NB}}\big(x_c\mid \ell_c\,\rho(z_c,b_c),\,\theta\big)+\beta\,\mathrm{KL}\big(q(z\mid x_c)\,\|\,\mathcal{N}(0,I)\big)$$ $$\mathcal{L}_{\text{ct}}=\frac{1}{K}\sum_{k=1}^{K}\mathrm{CE}\big(y_c^{(k)},\hat y_c^{(k)}\big),\qquad \mathcal{L}_{\text{reg}}\ \text{同理}$$ $$\mathcal{L}_{\text{sp}}=-\frac{1}{n_i}\log p_{\text{NB}}\big(x_i\mid \ell_i\,\rho(\hat z_i,b_i),\,\theta\big)+\mathrm{CE}\big(y_i,\hat y_i\big),\qquad \hat z_i=f_{\text{nbr}}\big(\{\mu_j,\Delta p_j\}_{j\in\mathcal{N}(i)}\big)$$

\(M\)：被遮住的 (细胞, 基因)；\(\ell\)：文库大小；\(b\)：批次；\(\beta\) 在前 5,000 步从 0 线性升到 1；\(n_i\)：被隐藏细胞的已测基因数。

    05 · 模型架构

    Cell × Gene 表上的循环混合专家编码器。

    v0 与 v1 架构相同。注意力只在每个细胞自己的基因 token 之间做；每个 block 是注意力 + DeepSeek 式混合专家，带 N-BEATS 残差。中间两层训练时循环 2–6 次，评估时 4 次。

    Block 细节

    注意力

    FlashAttention-3 变长，4 头 × 64 维；每个细胞一条序列，不跨细胞、无 padding。

    混合专家

    32 个路由专家选 4 个 + 1 个共享专家；sqrt-softplus 路由，无辅助 loss 的偏置均衡；第一层按基因 ID 哈希路由。

    五个任务

    基因插补、scVI 式整合、层级细胞类型、层级脑区、空间邻居插补；v1 起按梯度范数均衡配平。

    优化

    隐藏层矩阵用分组 Muon，其余 AdamW；每步 128 个解离细胞 + 16 个空间组，约 31 万 token。

    Infra

    单张 H20 上每步 2.90 → 0.85 秒，MFU 约 16% → 50%；推理 1 万细胞约 18 秒。

    规模

    可学习参数 94.0M：编码器 58.4M（基因嵌入 16.9M，6 个 block 41.4M，其中路由专家 37.7M），预训练头 35.6M（负二项解码器 34.0M，主要是输出到 65,918 个基因的一层）。每个 token 激活约 17M：混合专家 32 选 4，Core 循环 4 次共 12 次 block 调用（循环 2–6 次时 11–23M）。把循环展开成独立的层，等价于 135M（108–163M）。d = 256，潜变量 64 维。
